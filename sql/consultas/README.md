# Consultas

Consultas `SELECT` para relatórios e para validar o banco.

## Relatórios

Execute depois de todos os scripts de `sql/ddl/`.

| Arquivo | Relatório |
| --- | --- |
| `01_agendamentos_do_dia.sql` | Agendamentos do dia, com pet, tutor e telefone do tutor |
| `02_valores_recebidos_no_mes.sql` | Valores recebidos no mês atual, com descrição e total |
| `03_atividades_dos_veterinarios.sql` | Atendimentos e procedimentos de cada veterinário, com o pet |
| `04_internados_e_pagamentos.sql` | Pets internados, com valores pagos e pendentes |
